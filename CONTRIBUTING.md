# Contributing

1. Read `AGENTS.md`, `docs/MASTER_PLAN.md`, and `docs/tasks/ACTIVE.md`.
2. Work from an approved task and a branch; do not work directly on `main`.
3. Keep the Mini Program read-only and aligned with the canonical Admin Web identity/API contracts.
4. Add or update tests and evidence with each behavior change.
5. Run every available verification script plus `git diff --check` and a secret scan.
6. Hand work to `REVIEW`; do not self-assign `DONE`.

Do not add dependencies without recording their source, version, maintenance/security rationale, and why platform APIs or current dependencies are insufficient.
