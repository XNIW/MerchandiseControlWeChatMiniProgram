# WMP-013 — Product database and product images

- Parent: `WECHAT-002`
- Status: `REVIEW`

Implementation evidence: bounded catalog/detail pages, search/filter/sort, stale-request suppression, batched image resolution, lazy thumbnails, main-image detail, placeholders and bounded image/page caches are present. DevTools visual and live Storage authorization remain review gates.

## Scope

Deliver a searchable/filterable/sortable, keyset-paginated product database and product detail. Reuse the existing private product image/version model with short-lived signed thumbnails and detail images generated server-side.

## Acceptance criteria

- Fields are schema-backed; no invented availability, margin or business metadata.
- Lists use thumbnails only, lazy loading, placeholders and bounded caching.
- Image lookup is batched; the bucket remains private; shop A cannot resolve shop B images.
- Requests are debounced and obsolete responses are ignored.

## Required tests

Catalog search/filter/cursor tests, 20k-product EXPLAIN evidence, image-present/missing/cross-shop tests, signed-URL TTL assertion, client unit/build tests.
