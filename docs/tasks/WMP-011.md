# WMP-011 — Sales history and date navigation

- Parent: `WECHAT-002`
- Status: `REVIEW`

Implementation evidence: bounded day/preset-range summaries, daily totals, keyset sales list, supported filters, conditional operational metadata, detail route, pull refresh and last-page cache are present. Live financial fixtures and DevTools QA remain external review gates.

## Scope

Add bounded date/range summaries, daily grouping, date navigation, supported filters, keyset pagination, sale detail, pull-to-refresh, shop timezone/currency formatting and a bounded last-page cache through Admin-owned APIs.

## Acceptance criteria

- No full-table sales load; page limits and cursors are enforced on client and server.
- Shop/date/range inputs are validated; authorization is rechecked for every read.
- Detail exposes only schema-backed, authorized fields.
- Empty, offline, expired-session and retry states remain usable.

## Required tests

Unit/API tests for ranges, cursor validation, detail, cache and stale-request suppression; pgTAP for anonymous, cross-shop, revoked membership and suspended shop; typecheck/lint/build.
