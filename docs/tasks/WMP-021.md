## Context and objective

Decide whether Excel import can be exposed safely through a small Mini Program adapter without duplicating parsing, mapping, normalization, preview/apply, audit or sync. The Admin decision `docs/DECISIONS/DEC-002-mini-program-excel-import-gate.md` records that the current gate fails even though the canonical Admin parser is mature: bearer context propagation, resource bounds, rate limiting and partial/indeterminate apply recovery are not yet sufficient for a public Mini surface.

The correct outcome for this wave is deferment. No fake import button, placeholder wizard or client workbook parser is permitted. This does not block controlled single-entity catalog CRUD.

- Official Mini Program file-selection/upload limits if the decision is reopened.

## Out of scope
