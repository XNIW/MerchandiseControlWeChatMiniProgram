# WMP-014 — Suppliers, categories and price history

- Parent: `WECHAT-002`
- Status: `REVIEW`

Implementation evidence: searchable bounded category/supplier pages with server counts and linked catalog filters, plus bounded product price history, are present. Live cross-shop checks remain external.

## Scope

Add read-only, searchable and paginated categories/suppliers with product counts and associated products, plus current and paginated historical price views.

## Acceptance criteria

- Every result is active-row and shop scoped.
- Counts and product associations are computed server-side without N+1 client calls.
- Price source is returned only when present and authorized.

## Required tests

Anonymous/cross-shop/revoked membership tests, bounded pagination, empty history and wide-history fixtures, typecheck/lint/build.
