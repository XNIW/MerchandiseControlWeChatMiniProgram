# Task ledger

- `ACTIVE.md`: the single task currently in PLANNING/EXECUTION/FIX.
- `PLANNED.md`: ordered inactive backlog.
- `REVIEW.md`: work handed to independent review.
- `DONE.md`: only explicitly approved completed work.
- `templates/TASK_TEMPLATE.md`: required task contract.

Task transitions and evidence rules are defined in `docs/WORKFLOW.md`. History is append-only in `docs/TASK_HISTORY.md`.
