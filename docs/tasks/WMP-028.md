## Context and objective

Ensure a Mini session can use only controlled Admin routes and cannot use
legacy catalog tables/RPCs to bypass flags, CAS, receipts, rate limits or audit.

## Dependencies and files to read

- ADR-003, opaque-session migration/helper, BFF routes and SessionStore.

## In scope

- Server-hashed opaque token, canonical actor/surface/device/expiry/generation
  binding, revocation/logout, service-only wrappers and per-call authorization.

## Out of scope

- Client-authored surface claims, general Supabase bearer handoff, user metadata
  authorization or changes to Android/iOS/Admin personal-auth lanes.

## Files potentially involved

- Admin Auth/session/BFF SQL and Mini Auth/session clients/tests.

## Acceptance criteria

- [x] Mini controlled reads/mutations pass with the opaque session.
- [x] Direct legacy RPC/table attempts cannot authenticate with that token.
- [x] Viewer/cross-shop/revoked/suspended/expired/flag-OFF cases deny.
- [x] Service role and Supabase access/refresh tokens are absent from clients.
- [x] Android/iOS/Admin existing personal-auth regressions pass.
