# Workflow

## PLANNING

Define the objective, scope, required reading, dependencies, acceptance criteria, checks, and risks. Update the task before implementation if the contract changes.

## EXECUTION

Only one application task may be active per writer. Keep a factual worklog, make bounded changes, and do not expand scope silently.

## REVIEW

Review the full diff, tests, build, security boundaries, documentation, evidence, and residual risks. Classify the result without treating unrun live tests as passed.

## DONE

Requires satisfied acceptance criteria, no open P0/P1 issue, a positive review, and explicit user/designated-reviewer confirmation. Codex cannot self-approve it.

## BLOCKED_EXTERNAL

Record the exact external cause, action owner, unblock procedure, and independent work still possible. This state does not suspend unrelated safe work.
